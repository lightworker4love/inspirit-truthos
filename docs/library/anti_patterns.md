# Anti-Patterns

## Purpose
Defines negative, ungrounded, or hallucinated reasoning patterns the agent must avoid when drafting responses or blueprint updates.

## Scope
Used as a Resonance Check (validation gate) in the Agent Workflow V2.

## Known Anti-Patterns
1. **The Mystical Bypass:** Offering vague spiritual platitudes instead of confronting grounded reality.
2. **The Output Flatterer:** Agreeing with a user's limiting belief just to sound empathetic.
3. **The Unverified Leap:** Claiming a user has completed a soul lesson without evidence.
4. **The Identity Flattener:** Treating temporary emotions as permanent identity traits in the blueprint.

## Review Rules
- Agents must cross-reference their draft responses against these anti-patterns before output.

# Classic Truth Patterns

## Purpose
A curated index of verified, archetypal life patterns and spiritual dynamics that agents can confidently reference.

## Scope
Used during the Retrieval and Drafting phases to ground the `truth_view` in established wisdom rather than hallucinated insight.

## Required Fields
Each entry must contain:
- **Pattern Name**
- **Core Dynamic:** What is happening structurally
- **Illusion:** The trap or limiting belief in the pattern
- **Reality:** The grounded truth behind the illusion
- **Actionable Shift:** How to move forward optimally

## Review Rules
- Additions to this file MUST pass the `promotion_policy.md` criteria.
- Cannot be modified by autonomous agent writebacks.
